BOOKS GATE - STARTER V1

1. Dans Supabase : Project Settings > API
2. Copie Project URL et la clé publique anon/publishable.
3. Ouvre config.js et remplace les 2 valeurs.
4. N'utilise JAMAIS la clé service_role dans le site.
5. Envoie tous les fichiers dans le dépôt GitHub books-gate.
6. GitHub > Settings > Pages > Deploy from a branch > main > /(root) > Save.

Tu auras ensuite un site du type :
https://TON-COMPTE.github.io/books-gate/

Cette V1 contient :
- accueil TMB 63 / TMB 70
- liste des books
- badge NOUVEAU pendant 7 jours
- page book avec rangs, familles, produits
- connexion Admin

Prochaine étape :
- bouton Ajouter un book
- import Excel
- photos
- création automatique familles/produits
- publication/suppression
